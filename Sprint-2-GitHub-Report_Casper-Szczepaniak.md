## Sprint 2 Overview

During Sprint 2, I focused on developing the core functionality and user interface of the TrainFUEL application. My contributions included Firebase authentication, the main Home dashboard, nutrition tracking, user profile and fitness information, and personalized sport-specific hydration recommendations.

The goal of these features was to create a functional foundation for TrainFUEL that allows users to sign in, track nutrition information, view fitness-related data, and receive recommendations based on their goals and selected sport.

## Features Implemented

### Home Dashboard

- Developed the main TrainFUEL Home screen.
- Added daily calorie and protein summaries.
- Added meal count tracking.
- Added fitness and training information to the dashboard.
- Connected nutrition information to the Home screen so users can quickly view their daily progress.
- Added personalized nutrition and hydration recommendations.

### Firebase Authentication

- Integrated Firebase Authentication into TrainFUEL.
- Added user account creation functionality.
- Added login functionality for existing users.
- Added authentication state handling for signed-in users.
- Added logout functionality.

### Nutrition Tracking

- Added functionality for users to log meals.
- Added calorie and macronutrient tracking.
- Added tracking for protein, carbohydrates, and fat.
- Added daily nutrition totals.
- Added support for removing logged meals.
- Integrated nutrition information with the Home dashboard.

### Profile and Fitness Features

- Developed the user Profile interface.
- Added user information and fitness goal display.
- Added calorie and protein target information.
- Added fitness progress information.
- Added training-focused information to support the user's fitness goals.

### Hydration Recommendations

- Implemented personalized hydration recommendations.
- Hydration recommendations change based on the user's selected sport.
- Integrated hydration recommendations into the Home screen alongside nutrition recommendations.
