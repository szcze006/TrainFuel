## Blockers & Scope Changes

### Major Blockers
- Jira issues for most Sprint 3 work were created late in the sprint, after development had started, so the board did not reflect progress until October 19-20.
- New features that save data to Firebase (meal dates, profile measurements, per-day training notes) required Firestore data and security rule updates and additional testing.

### Scope Changes

- 19 issues (62 story points) were added during Sprint 3, covering the Sports Coach, Performance Hub, nutrition, profile and authentication work.
- TFUEL-35 (Add Apple Sign In) was not included in Sprint 3 and remains in the backlog.
- TFUEL-52 (Persist Hydration and Recovery Data) was created during the sprint but left in the backlog for a future sprint.

### Work Spilled Over

- No Sprint 3 work spilled over. All 20 issues in the sprint were completed.
