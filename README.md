# TrainFuel

TrainFuel is a sports nutrition and fitness application designed for people who exercise or participate in sports. The app provides personalized nutrition and training recommendations based on the user's sport, fitness goal, body information, and activity level.

## Project Purpose

Different sports require different approaches to training and nutrition. TrainFuel is designed to give users recommendations that match the sport they participate in and the fitness goal they are working toward.

## Main Features

- Personalized daily calorie and macronutrient targets
- Sport-specific nutrition recommendations
- Sport-specific workout recommendations
- Meal logging
- Workout logging
- Weight and progress tracking
- User profiles with customizable fitness goals

## Supported Sports

- Soccer
- Basketball
- Football
- Running
- Weightlifting

## Fitness Goals

- Build muscle
- Lose fat
- Maintain weight
- Improve athletic performance
